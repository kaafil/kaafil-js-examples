Kaafil browser demo

This half proves that a browser tab can drive the on-ground manager view without ever holding a partner API key. It never imports kaafil-js, only kaafil-js/client — a separate module graph that cannot reach the API-key code path at all. Paste the accessToken and refreshToken that the server half's auth.mintManagerToken call printed for you, and this page will open a session with them.

4. Rooming board

Every chip below is drawn from two fields the engine already computed for that traveller: glyph (their initials) and tone (a token like male.3 — never a hex). This page runs no colour maths at all: it does not hash a traveller id, index a palette, or branch on gender. occupantChip() renames the token into two CSS classes, and styles.css — the consumer's own design system — is the only place an actual colour appears. That split is why the same traveller looks the same here, on the seating grid, and in any other screen that reads the same canon.
